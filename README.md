# 知习 · 微信刷题小程序

依据《微信刷题小程序需求规格说明书》和《参考架构》实现的原生微信小程序客户端。当前版本可直接使用内置演示数据运行，覆盖单词学习、考公/考研题库、错题与收藏、历史记录和学习统计等 V1 核心流程。

## 已实现内容

- 4 个主导航：首页、学习、题库、我的。
- 33 个页面：登录、真题上传、题库分级选择、练习配置、答题、题卡、练习报告、错题、收藏、历史，以及单词书、学习、复习、测试、进度和个人统计等页面。
- 单选、多选、判断题与材料题；顺序、随机、专项、错题、收藏练习。
- 固定练习会话题序，答题前不向页面提供正确答案和解析，提交后再返回判题结果。
- 重复提交保护、错题自动汇总、收藏去重、连续答对后自动掌握、答题历史与报告。
- 单词“先回忆、再揭示、四级反馈”流程；按“不认识 / 模糊 / 认识 / 熟练”计算下次复习时间。
- 每日学习目标、日历、本周/本月/累计统计、科目分析和薄弱知识点。
- 本地持久化演示数据，退出后学习记录仍保留；可在“我的 → 关于知习”中重置。

## 界面与功能入口

界面采用轻边框、统一间距和简洁列表，去除大面积渐变、装饰图形与重阴影。

- 首页突出继续学习，提供单词、考公、考研入口及今日进度，最近练习最多展示两条。
- 学习页保留每日任务；完整趋势、正确率和薄弱点通过“学习统计”“薄弱知识点”查看。
- 题库页集中展示学习方向、错题本和收藏，不展示尚未实现的模拟考试占位。
- 题库页将“考公真题”“其他题”和内置专项题库分开；支持直接上传 PDF，也保留 JSON 导入。题目经预览、校验后保存在本机，可直接组卷、判题、加入错题本或收藏。
- “我的”集中提供资料、统计、错题、收藏、生词本、历史和设置。
- 单词页集中展示当前词书、新词与复习任务，测试、词书、生词本和进度均保留。
- 答题、练习配置、报告、词书和统计等二级页面同步采用紧凑布局。

## 如何运行

1. 安装并打开微信开发者工具。
2. 选择“导入项目”，项目目录选择本仓库根目录。
3. `project.config.json` 已配置当前小程序 AppID；如需迁移到其他账号，请替换为对应 AppID。
4. 项目同时保留 TypeScript 源码与已编译 JavaScript，导入后即可从登录页开始体验。

项目配置入口为 `project.config.json`，小程序源码位于 `miniprogram/`。

## 演示数据

当前客户端使用本地 Mock 服务，内置：

- 2 个考试分类：公务员考试、全国硕士研究生招生考试；
- 5 个科目、19 个章节及对应知识点；
- 100 道原创示例题，涵盖单选、多选、判断和材料题；
- 3 本单词书、15 个示例单词。

所有答题、收藏、错题、单词和统计数据均保存在微信本地存储中。选择的 PDF/JSON 题库也在本机解析，文件内容和提取出的文本不会上传网络。

## 上传真题

1. 准备含有可搜索、可复制文字的 PDF 真题；如需精确控制题目字段，也可使用 `docs/question-bank-template.json` 制作 JSON 题库。
2. 将 PDF 或 JSON 文件发送到微信“文件传输助手”或任意会话。
3. 在小程序“题库 → 上传”中选择“考公真题”或“其他题”，再选择 PDF 或 JSON 文件。
4. 核对试卷名、来源、年份及题型统计后确认导入。

PDF 文件不得超过 10MB，当前仅支持含文本层的 PDF。扫描版或纯图片 PDF、加密/带密码 PDF，以及以图片、表格、复杂排版为主的题目暂不能可靠识别；这类文件需要先进行 OCR 或人工整理为 JSON，本版本不包含 OCR 功能。

JSON 导入继续支持，单个文件可包含 1～200 题且不得超过 700KB，支持单选、多选、判断和每题附带材料；考公真题固定归入行测，“其他题”需在文件根节点填写现有科目。模板见 [题库导入模板](docs/question-bank-template.json)。Word 和 Excel 暂不直接解析，可先整理为模板 JSON。

## 正式上线前

本次交付范围是微信小程序客户端，不包含需求文档中的 Spring Boot 服务端和 Vue 管理后台。正式环境需要完成以下工作：

- 将 `miniprogram/services/api.ts` 的本地实现替换为真实 `/api/v1` 接口；`miniprogram/services/http.ts` 已提供 Token 请求封装。
- 使用 `wx.login` 的临时 code 在服务端换取登录态，并实现 Token 刷新、失效重登和接口错误码处理。
- 正确答案和解析必须只保存在服务端；`data/answer-keys.ts` 仅用于离线演示，不能随正式客户端发布。
- 配置正式 AppID、HTTPS 合法域名、隐私政策、用户协议、内容版权与反馈入口。
- 在服务端落实练习会话固定题序、提交幂等、错题唯一约束、统计聚合和数据备份。

模拟考试、排行榜、社区、AI 解析与单词拼写属于后续版本规划，本版本未启用。
